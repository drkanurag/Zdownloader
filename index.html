Why did GitHub Pages show "Failed to fetch"?

Because GitHub Pages is loaded over secure HTTPS, modern browsers (Chrome & Edge) block direct requests to insecure HTTP local addresses (http://127.0.0.1) as Mixed Content.

To allow this GitHub page to connect to your local PC in Chrome/Edge:
1. Click the tune / site settings icon on the left side of the address bar.
2. Click Site settings ➔ Set Insecure content to Allow.
3. Reload this tab and click "Retry Connection".

💡 Or simply use http://127.0.0.1:8765 directly — no permissions or flags required!
